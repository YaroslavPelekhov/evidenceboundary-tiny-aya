# Scope and exclusions

This repository distributes original project software, synthetic input records and target labels, created documentation, and aggregate metrics only. Dataset labels are not Cohere outputs. No provider responses, case-level response scores, native AuditKIT exports, inference logs, account identifiers, credential material, approval receipts, or copied third-party implementation/assets/weights are included.

CuratorKIT and AuditKIT are external dependencies, not vendored. Their respective licenses continue to govern their software. Tiny Aya Global is documented upstream under CC-BY-NC 4.0 with the Cohere Labs acceptable-use addendum; no weights or model license are relicensed here. Model and demo terms do not automatically establish rights to distribute hosted outputs. No such rights clearance is asserted.

Source URLs: https://github.com/Lexsi-Labs/CuratorKIT ; https://github.com/Lexsi-Labs/AuditKIT ; https://huggingface.co/CohereLabs/tiny-aya-global ; https://cohere.com/cohere-labs-cc-by-nc-license ; https://docs.cohere.com/docs/cohere-labs-acceptable-use-policy

The public AuditKIT smoke module and its tests are original MIT-licensed project code. Generated smoke artifacts are synthetic fixtures only and are not included in the repository.
