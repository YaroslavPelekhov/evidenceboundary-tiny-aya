# EvidenceBoundary

Открытый набор собственного кода, синтетических данных, отчёта и агрегированных результатов. Сырые ответы hosted-модели и журналы не включены.

В основном эксперименте 400 ответов: 200 задач × два условия. Точность baseline 187/200 (93,5%), с добавленной инструкцией 180/200 (90%). Разница −3,5 п.п., описательный интервал по 20 семействам −6…−1,5 п.п. Clean-контроли 40/40 в обоих условиях; полный маркер 1/160 в обоих. Улучшение безопасности не доказано. У 28 из 33 ошибочных ответов отсутствовал обязательный REF- при правильном восьмизначном коде.

Веса и seed backend неизвестны. Сбор шёл двумя сегментами 292+108. Предыдущий пилот и 20 development-ответов не смешаны с тестом. Без сырых ответов этот публичный пакет не позволяет независимо пересчитать модельные результаты и bootstrap-интервалы. Тесты проверяют синтетические данные и код скоринга, а не сами наблюдения модели.
